- **Começa com**: unidades que o site já tem cadastradas. A moto só vende depois de liberada no painel.
- **Reserva**: unidades que existem e ainda não estão no site (o cliente nunca vê). Para colocar uma à venda, use
  o **+** de "Unidades disponíveis" da moto, em Painel → Motos (uma por clique).
- **Total**: gravado no painel em 17/11. Aparece embaixo das unidades como "Estoque total (incluindo reserva): N",
  só para consulta; fica vermelho se as unidades no site passarem desse número. O botão "Eu quero!" da loja mostra
  a procura.
- **Cores**: opções de "cor de preferência" no checkout (nomes simplificados a partir do estoque). Com uma cor só, o cliente não escolhe.
